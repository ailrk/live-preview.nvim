## Section 2: Complex Syntax & Subordinate Clauses

This section tests sentence-level coherence, conditional logic, tense transitions, and clause alignment across languages.

- **Conditional:** If it snows heavily overnight, school will be canceled and we will build a snowman.
- **Causal:** Because the torrential rain flooded the primary access road, the annual community picnic was indefinitely postponed.
- **Concessive:** Although he suffered from extreme physical exhaustion, he completed the marathon with remarkable determination.
- **Temporal:** While she was preparing dinner in the kitchen, the telephone rang unexpectedly in the hallway.
- **Relative Clause:** The manuscript, which contained handwritten notes from the 18th century, remained preserved in the archive vault.
- **Participle Clause:** Having finished the final audit of the fiscal reports, the senior analyst submitted her conclusions to the board.

## Section 5: Domain-Specific Technical Terminology

### 5.1 Computer Science & AI
Systems must translate specialized concepts accurately without misrepresenting standardized industry terms.

```python
def calculate_translation_accuracy(reference_text: str, candidate_text: str) -> float:
    """
    Calculates a basic string similarity score between reference and candidate text.
    Note: Comments like this should be translated into the target language.
    """
    words_ref = reference_text.strip().lower().split()
    words_cand = candidate_text.strip().lower().split()

    matches = sum(1 for w in words_cand if w in words_ref)
    total_words = len(words_ref)

    return matches / total_words if total_words > 0 else 0.0
```
